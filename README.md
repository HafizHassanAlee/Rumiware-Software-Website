# Rumiware Software Website

Rumiware Software Website is a beginner-level website project created to practice **HTML and CSS** and to build a simple software-house style landing page.

> **This is my first project using HTML and CSS.**

The project focuses on creating a clean landing page for Rumiware with a navigation header, hero section, service cards, buttons, hover effects, animations, and basic responsive behavior.

## 🌐 Live Website

[View the live website](https://rumi-ware.github.io/Rumiware-Software-Website/)

## 📌 About the Project

The website represents a simple software-house homepage for **Rumiware**.

It introduces the company through a hero section and presents three example services:

* Build Your Presence Online
* Digital Modernization & Platform Upgrades
* Growth-Oriented Websites

This project is intentionally kept at a beginner-friendly level so that the HTML structure and CSS styling can be understood and improved step by step.

## 🛠️ Technologies Used

* **HTML5** — webpage structure and content
* **CSS3** — styling, layout, colors, cards, buttons, hover effects, animations, and responsive design
* **Google Fonts** — typography
* **Git & GitHub** — version control and project hosting
* **GitHub Pages** — website deployment

## ✨ Main Features

### Header and Navigation

* Rumiware logo/name
* Home navigation
* Services navigation
* About navigation
* Contact navigation
* Get Started button

### Hero Section

A large headline introduces the website and communicates the purpose of the Rumiware software-house brand.

### Services Section

The website contains three service cards.

Each card includes:

* Service title
* Short description
* Get Started button

### Hover Effects

CSS hover effects are used on the cards and buttons to make the website more interactive.

### Responsive Design

CSS media queries are included to make the service cards adapt to smaller screen sizes.

On smaller screens, the cards change from a horizontal layout to a vertical layout.

### CSS Animation

A simple CSS animation is included that allows an element to move into view from the left side.
